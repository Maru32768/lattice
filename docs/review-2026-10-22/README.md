## 横断した原因

レビュー 2（使ってみた結果、R1〜R6）とレビュー 3（モデルの照合、D1〜D13）は別の方法で調べたが、同じ原因に行き着いたものが多い。

| 原因 | 根拠 | roadmap |
|---|---|---|

## 修正の結果

3 つのブランチをそれぞれ worktree で作り、master にマージした（`09fb996`・`0c33357`・`0afe98a`）。

**backend・CLI・MCP**（11 件すべて対応。8 は英語のみ）

- 難易度を「未判定」に戻すと、もう一度推定する（1-1）。
- メインウィンドウの位置と大きさを覚える。最大化の状態は復元しない（`shortcut:` コメントあり）（1-2）。
- Claude CLI を専用の空フォルダ `%TEMP%\lattice-claude` で動かす（1-4）。
- 選んだデータフォルダに `lattice.db` がなければ、既定の場所で起動する（1-5）。
- CLI に `collections` コマンドを追加。scope に `collection:ID`（`group:ID` も使える）・`genre:none`・`feed:none` を追加。`important` の既定は設定のしきい値（1-13, D7, D8）。
- `get --blocks --format text` で block を出す（1-14）。
- MCP のエラーにも信頼できない内容の注記を付け、25,000 字の上限を守る（1-17）。
- コレクションのエラー文を英語では "collection" と書く。日本語は I8 で決める（2-4.4）。
- フィードの記事は entry のタイトルを使う（2-4.1）。
- DNS・接続拒否・タイムアウト・TLS の取得エラーを定型文にする（2-4.14）。
- Retry now で試行回数と次の実行時刻が進む（2-4.9）。
- `native-tls` を lattice-core の直接依存に追加した（reqwest 経由ですでに入っていたもの）。

**一覧・ナビ・検索・Jobs**（11 件中 9 件に対応、1 件は一部）

- 対話の引用とパレットの項目を、Ctrl+クリック・中クリックで新しいタブに開く（1-3）。
- Jobs に種類の名前を出し、ID は tooltip に回す（1-6, 2-4.16）。
- ペインが 1 つのときは `Ctrl+B` `x` で何もしない（1-7）。
- 検索の範囲のメニューを対話と同じ `filterGroups` から作り、フォルダと「重要」を足した（1-8, D3, D4）。
- 「Source」でまとめたときの見出しをフィードの並び順にする（D3）。
- Esc で選択モードを抜ける（2-4.7）。
- 0 件のときは facet・並び順・Select を出さない（2-4.13）。
- 一覧の注記を 1 行に収め、全文は tooltip に出す（2-4.6）。
- 削除したフィードを「Feed {id}」ではなく「削除したフィード」と出す（D9）。
- 日本語の並び替えメニューを「並び順とまとめ方」にし、コレクションの「グループ」と分けた。コレクションのアイコンは決めていない（D6）。
- **見送り**: 重要度の「未判定 0」（2-4.3）。ほかの絞り込み（ジャンル・状態）がかかった状態での件数なので、正しい値だった。

**設定・Reader・取り込み**（8 件すべて対応）

- Reader の " block" を i18n にした（1-9）。
- 古い説明文 4 つを実装に合わせた（1-16）。
- AI プロバイダの行を折り返し、select の最小幅を保つ（2-4.5）。
- 一括取り込みは、送信した後で入力欄を空にする。捨てた行の数と理由を出す（2-4.8, 2-4.10）。
- Find のエラーを入力欄の直下に出す（2-4.11）。
- 一覧と Reader で、翻訳の件数を同じ計算にする（2-4.12）。
- かなを含むときだけ日本語とみなす。漢字だけの中国語も翻訳の対象になる（Rust と overlay の両方）（2-4.2）。
- 翻訳するものがない記事では、理由を表示する（2-4.15）。

**確認していないこと**: 実際の Tauri アプリでの見た目と動作。特に、メインウィンドウの位置の復元と、狭い幅でのレイアウト。テストは単体テストと、モックの backend を使う e2e だけ。
