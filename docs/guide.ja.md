## 画面の構成

メインウィンドウは、左から次の 5 つの領域でできています。

- **タイトルバー。** ‹ › で、アプリ内で移動した場所を戻る・進むできます。中央の箱（「検索・コマンド・URL」、`Ctrl+K`）でコマンドパレットを開きます。
- **ナビゲーション。** 左のサイドバーです。記事の一覧（「ライブラリ」「グループ」「ジャンル」「ソース」）、「ツール」（「対話」「今日の復習」「単語帳」「処理状況」「一括インポート」）、いちばん下に「設定」があります。
- **記事一覧。** ナビで選んだ一覧の記事です。上に絞り込みと並び順があります。
- **文書エリア。** 記事や Web ページをタブで開く場所です。複数のペインに分割できます。
- **対話ペイン。** 「対話」を押すと右に開きます。

領域の境目をドラッグすると幅を変えられ、ダブルクリックで元の幅に戻ります。幅は保存されます。ナビの上端のボタンでナビを、記事一覧のボタンで一覧を閉じられます。閉じた一覧は細いレールになり、そのボタンでまた開きます。

設定・処理状況などの画面は、記事一覧と文書エリアの場所に表示されます。`Esc` でライブラリに戻ります。

ライブラリが空のときは、文書エリアに「最初の記事を入れる」が出ます。URL の貼り付け・フィードの登録・一括インポート・Markdown の取り込みにそこから進めます。AI プロバイダを設定するまでは、それが必要な機能を知らせる案内が出ます。保存・閲覧・全文検索はプロバイダなしで使えます。

## 記事を集める

Lattice は記事ごとに本文・画像・抽出元の HTML を保存します。元のページが消えても読めます。

### URL を保存する

1. `Ctrl+K` を押します。
2. URL を貼り付けます。
3. 「Index に追加（取り込み）」を選ぶか、`Ctrl+Enter` を押します。

パレットには、保存せずにページを開く「Page で開く」と、「フィードを検出して登録」も出ます。保存済みの URL なら「Reader で開く」で保存した記事を開けます。一覧でグループを開いているときは、URL をそのグループに入れて保存する項目も出ます。

URL は先に正規化します。トラッキング用のパラメータを外し、保存済みの URL なら既存の記事を開きます。取得に失敗した記事を保存し直すと、取得をやり直します。

### 閲覧中のページを保存する

Page 表示はアプリ内のブラウザです。表示中のページを保存するには、ツールバーの「Index に追加」を押します。ブラウザが描画したままのページを保存するので、JavaScript で描くページやログインが必要なページも欠けずに入ります。保存したページはツールバーに「Index 済み」と出て、Reader・タグ・ジャンル・お気に入りが使えるようになります。

### フィードを登録する

RSS と Atom のフィードを読めます。ナビの「ソース」の横の「管理」か、パレットから「フィードを管理」を開きます。

**サイトのフィードを探す。** サイトか記事の URL を入力して「検出」を押します。URL がフィードならそれを使います。そうでなければページの中のフィードへのリンクを探し、次に `/feed` や `/rss.xml` などのよくある場所を試します。候補が複数あれば 1 つ選んで「登録して最新 20 件を取り込む」を押します。

**まとめて登録する。** フィードの URL を 1 行に 1 つずつ貼ると、リンクを探さずにそれぞれを登録します。

**更新のタイミング。** 起動時と 30 分ごとに全フィードを確認します。新しく登録したフィードは最新の 20 件を取り込み、その後は新着だけを取り込みます。「すべて更新」で今すぐ確認します。各フィードの行には、状態・最終更新・未読数と記事数が出ます。「記事を見る →」でそのフィードの記事を開きます。フィードを削除しても記事は残り、「手動追加」に移ります。

**フォルダ。** フォルダはフィードをまとめるものです（たとえば、チャンネルごとに RSS を出すサービスのフィード）。フィードが入るフォルダは 1 つまでで、フォルダの入れ子はありません。

- フォルダを作るには、「フォルダ」の欄に名前を入れて「作成」を押します。名前の変更・並べ替え・削除もそこでできます。
- フィードを移すには、フィードの行でフォルダを選びます。複数のフィードにチェックを付けて「フォルダへ移動…」でまとめて移すこともできます。
- 登録と同時にフォルダへ入れるには、登録する前に「追加先のフォルダ」を選びます。
- ナビでは、フォルダは開閉できる行になります。数は配下のフィードの未読の合計です。押すと配下のフィードすべての記事が一覧に出ます。右クリックか ⋯ で名前の変更と削除ができます。フォルダを削除してもフィードは残ります。

**フィードの順序。** フィードは、フォルダの中と、フォルダに入っていないフィードの中で、並べた順を保ちます。アプリの中でフィードを並べる場所（ナビ、フィードの管理画面、パレット、範囲の選択、OPML の書き出し、CLI）はすべてこの順です。

- ナビのフィードをドラッグして別のフィードの上で離すと、その位置に入ります。同じフォルダでも別のフォルダでもかまいません。
- フォルダの行の上で離すと、そのフォルダの最後に入ります。折りたたんだフォルダでも同じです。
- フォルダから出すには、フォルダに入っていないフィードの間で離します。すべてのフィードがフォルダに入っているときは、ドラッグ中だけ最後に「ここに置くとフォルダから出します」という枠が出ます。
- フォルダの行をドラッグすると、フォルダの順序を変えられます。中のフィードも一緒に動きます。
- フィードかフォルダの行にフォーカスがあるときは、`Alt+↑` と `Alt+↓` で 1 つずつ動かせます。フォルダの先頭や末尾を越えたフィードは隣のフォルダに入り、そのフォルダが閉じていれば開きます。
- フィードの管理画面でも、フィードはフォルダごとに同じ順で並び、行ごとの ↑ と ↓ のボタンで動かせます。

フィードやフォルダを短くクリックしたときは今までどおり開きます。動くのはドラッグしたときだけです。

**名前とアイコン。** フィードの行の「編集」で「表示名」と「アイコン」（PNG・JPEG・GIF・WebP・SVG・ICO、1 MB まで）を設定できます。「元に戻す」でフィード本来の名前に、「サイトのアイコンに戻す」でサイトのアイコンに戻ります。アイコンを設定しなければサイトのアイコンを表示します。

**取り込みフィルタ。** フィードの新着のうち、どれを取り込むかを決めます。すべてのフィードに効く全体のフィルタ（「設定 › 取り込みフィルタ」）と、フィードごとのフィルタ（「編集」の中）があり、両方を通った記事だけを取り込みます。

- 「ルール」は、「タイトル」「URL」「著者」「カテゴリ」「ドメイン」「言語」にキーワードか正規表現を当てます。大文字と小文字は区別しません。除くルールのどれかに合う記事は取り込みません。含むルールがあるときは、そのどれかに合う必要があります。
- 「本文の最短文字数」は、本文がそれより短い記事を除きます。本文を載せているフィードにだけ効きます。
- 「ルールを通った記事を LLM で判定する」をオンにすると、タイトル・抜粋・「自分について」・「取り込む記事の指示」を AI プロバイダに送って判定します。「重要度の下限」を選ぶと、1〜5 の点数で決めます。LLM の呼び出しに失敗したときは取り込み、フィードに理由を出します。
- 「除外された記事」に、フィルタで除いた記事が理由と一緒に残ります。「取り込む」で 1 件ずつ取り込め、「このルールを外す」で除外したルールを消せます。ルールを変えても過去の除外は自動では変わりません。「除外分を再評価」で今のルールを当て直します。

**OPML。** 「OPML を読み込む」で OPML ファイルのフィードを登録します。フィードを囲む outline はフォルダになります。「OPML に書き出す」はフォルダ付きでフィードを `exports` フォルダに書き出します。

### ファイルを取り込む

「ツール」の「一括インポート」を開きます。「インポート」の画面には 3 つのタブがあります。どのタブにも「グループ」の欄があり、取り込んだ記事をそのままグループに入れられます。

- 「URL 一覧」は、URL を含むテキストなら何でも読み込みます。URL の一覧、ブラウザのブックマーク（HTML）、CSV、JSON、ほかの read-later サービスのエクスポートなどです。テキストを貼るかファイルを選んで「インポート」を押します。取得はバックグラウンドで行い、新規・保存済み・無効な URL の件数を出します。失敗したページがあっても残りは続けます。
- 「Markdown」は、Markdown のファイル 1 つか貼り付けたテキストを 1 つの記事にします。タイトルは最初の見出し、なければファイル名か最初の行です。Web の URL の画像は保存します。相対パスの画像は、ファイルから取り込んだときだけ、そのファイルのフォルダから読みます。HTML のタグは取り込みません。取り込んだファイルには Web ページがないので、Page 表示は使えません。
- 「PDF」は論文などの PDF を 1 つの記事にします。本文の文字を読み、2 段組の読み順・見出し・キャプション・参考文献を組み立て直します。文字のない、画像だけの PDF は取り込めません。arXiv の `…/pdf/…` のような PDF の URL は、普通の URL と同じように保存でき、フィードからも取り込めます。

### JavaScript で描画するページ

JavaScript で描くまで本文がほとんどないページがあります。保存した記事の本文が空か短いと、一覧に「本文が短い」と出ます。「JS ページを自動で描画」がオンなら、裏の非表示ブラウザでページを描画して取り込み直します（1 件あたり最大 20 秒ほど）。描画した結果は、本文が増えたときだけ記事を置き換えます。

手で行うには、記事の ⋯ メニューで「描画して取り込み直す」を選びます。Page 表示では「表示中のページで取り込み直す」を選びます。今見えているページから取り込むので、ログインした後の内容も入ります。

ブラウザ以外からの取得を断るサイトもあります。フィードが記事の本文を載せていれば、Lattice はその本文で取り込み、Reader にそのことを表示します。Reader の「再試行」で元のページの取得をやり直せます。

## 記事を読む

### Reader と Page

保存した記事には 2 つの表示があります。ツールバーの左端の Reader と Page で切り替えるか、`v` を押します。

- **Reader** は抽出した本文を、見出し・リスト・コード・表・保存した画像と一緒に表示します。Web からは何も読み込みません。
- **Page** はアプリ内のブラウザで元の Web ページを表示します。翻訳と単語の登録は Reader と同じように使えます。

2 つのツールバーはそろえてあります。右端はどちらも同じボタンです: 「お気に入り」「既読にする」「質問」「理解度チェック」、フォーカスモード、⋯ メニュー。⋯ メニューには「再抽出（保存済みの HTML から）」、取り込み直す操作、「自動分類」「訳し直す」「要約を作成」「URL をコピー」「Index から削除…」があります。

再抽出は、保存してある HTML・PDF・Markdown から、ネットワークを使わずに記事を作り直します。Lattice の更新で抽出がよくなったときに使います。

**ブラウザ。** Page のツールバーには戻る・進む・再読み込み・「ホーム（検索エンジン）」があります。URL を押すと編集でき、`Enter` で開き、`Esc` で取り消します。URL でない語は、「設定 › ブラウザ」で選んだ検索エンジンで検索します。ログイン状態は次回の起動にも残ります。

取り込んだ Markdown と PDF のファイルには Page 表示がありません。URL から保存した PDF は、ブラウザの PDF ビューアで開きます。

### 表示する言語を選ぶ

Reader と Page のすぐ右の切り替えで、表示する言語を選びます。

- 「原文」は書かれたままの本文です。
- 「訳文」は翻訳です。
- 「混在」は両方を混ぜます。パーセントは訳文の割合です。`[` と `]` で 10% ずつ下げ・上げできます。

日本語の記事は英語に、それ以外の記事は日本語に訳します。アプリの表示言語を変えても、この向きは変わりません。どの部分を訳文にするかはページのアドレスと本文から決めるので、同じ記事はいつも同じ混ざり方になります。

この選択は、変えるまですべての記事とページに効きます。

### 1 つの段落だけ切り替える

「混在」か「訳文」で段落に少しの間ポインタを乗せると、もう一方の言語が吹き出しで出ます。吹き出しを押すと、その段落の言語が切り替わります。キーボードでは、段落にフォーカスを移して `Enter` を押します。Page 表示では同じ吹き出しが文ごとに出ます。

### 記事を翻訳する

Reader のツールバーに翻訳の状況が出ます（例: 「翻訳 12/40」）。

- 「表示を切り替えたら自動で翻訳」がオン（既定）なら、「混在」か「訳文」に切り替えると翻訳が始まります。
- 「翻訳する」で手動で始めます。一部だけ訳してある記事は「残りを翻訳」で続きを訳します。ボタンにポインタを乗せると、どちらの言語に訳すかが出ます。
- 「訳し直す」は、この記事の訳を捨てて、今のプロバイダと設定で訳し直します。訳が 1 つでもあれば ⋯ メニューに、全部訳してあればツールバーにも出ます。訳した段落が 50 を超える記事では確認があります。この記事の翻訳の実行中は使えません。
- 翻訳に失敗すると、ツールバーにエラー・次の自動再試行の時刻・「再試行」が出ます。訳し終えた段落は残るので、再試行で送るのは残りだけです。

訳は本文ごとに共有します。Page 表示で訳した段落は Reader でも訳してあり、その逆も同じです。そのため「訳し直す」は、同じ段落を持つほかの記事やページの訳も新しくします。

Page 表示で「混在」か「訳文」を選ぶと、読んでいるページをその場で訳します。ページの中ですでに訳先の言語で書かれた段落は送りません。

### 要約

Reader の上部の「要約」に「要約を作成」があります。要約は「自分について」を反映します。後から本文か要約の設定が変わると要約にそう表示され、「要約を作り直す」で反映できます。要約が勝手に作り直されることはありません。

保存した記事の Page 表示では、ツールバーの「要約」で同じ要約をページの上に表示できます。

### 記事の中の一致を見る

検索結果から記事を開くと、Reader に「一致 1 / 5」のような表示が出ます。「前の一致」と「次の一致」で一致した箇所を移動します。

### フォーカスモード

`f` かフォーカスモードのボタンで、ナビと記事一覧をまとめて隠します。もう一度 `f` で戻ります。一覧を隠していても `j` と `k` でカーソルは動きます。

### 戻る・進む

Lattice は移動した場所を記録します。画面・設定のセクション・一覧・絞り込み・フォーカスのあるタブの文書です。タイトルバーの ‹ ›、`Alt+←` と `Alt+→`、マウスの戻る・進むボタンで行き来できます。履歴は 50 件まで残ります。

Web ページにキーボードのフォーカスがあるときは、`Alt+←`・`Alt+→`・マウスのボタンはそのページ自身の履歴を移動します。Page のツールバーの ‹ › は、いつもページの履歴です。

### ページを印刷する

Page 表示で `Ctrl+P` を押すと、Windows の印刷ダイアログが開きます。

## タブ・ペイン・ウィンドウ

### タブ

文書エリアのペインごとにタブの列があります。タブには Reader の記事か Web ページが入ります。

- 一覧・パレット・検索結果・対話の引用から記事を開くと、フォーカスのあるペインのアクティブなタブの中身が入れ替わります。
- `Ctrl`+クリックか中クリックで、新しいタブに開きます。
- タブの列の端の「新しいタブ」（＋）は、検索エンジンのトップページを新しいタブに開きます。`Ctrl+T` はパレットを開き、そこで選んだものを新しいタブに開きます。
- `Ctrl+W`・タブの ×・タブの中クリックでタブを閉じます。`Ctrl+Tab` と `Ctrl+Shift+Tab` でタブを切り替えます。
- タブはドラッグで並べ替えられます。

タブとペインは次の起動で元に戻ります。隠れたタブの Web ページは 3 つまで読み込んだまま残すので、すぐに切り替えられ、スクロール位置も残ります。それより古いページは、戻ったときに読み込み直します。

### 文書エリアを分割する

- タブの列の「右に分割」「下に分割」で、フォーカスのあるペインを分割します。キーは `Ctrl+\` と `Ctrl+-` です。
- ペインの間の線をドラッグすると大きさが変わります。線にフォーカスを移して矢印キーでも変えられ、ダブルクリックで均等になります。
- 「ペインを閉じる」でフォーカスのあるペインを閉じます。タブがなくなったペインは消えます。
- タブを別のペインのタブの列にドラッグすると、そこへ移ります。ペインの中央に落とすとそのペインに入り、端の近くに落とすとそのペインを分割して新しい側に入ります。

フォーカスのあるペインには枠が付きます。ペインの中をクリックするとそのペインにフォーカスが移り、次に開く文書はそこに入ります。

### キーボードでペインを移動する

tmux と同じく、`Ctrl+B` を押してから次のキーを押します。

| `Ctrl+B` の後のキー | 動作 |
|---|---|
| `←` `→` `↑` `↓` または `h` `j` `k` `l` | その方向のペインへ移動 |
| `o` | 次のペインへ移動 |
| `%` | 右に分割 |
| `"` | 下に分割 |
| `x` | ペインを閉じる |
| `c` `n` `p` | 新しいタブ・次のタブ・前のタブ |
| `z` | フォーカスモード |

`Ctrl+B` が次のキーを待っている間は、画面にこのキーの案内が出ます。

### タブを別ウィンドウで開く

- タブの列の「別ウィンドウで開く」か `Ctrl+Shift+N` で、アクティブなタブを新しいウィンドウに移します。
- タブをタブの列からドラッグで離すと、30 ピクセルほどで新しいウィンドウになり、ポインタについて動きます。別のウィンドウのタブの列の上で離すと、そこに入ります。ドラッグ中に `Esc` を押すと元に戻ります。

文書ウィンドウは、タブの列がそのままタイトルバーです。列の空いた所をドラッグするとウィンドウが動き、ダブルクリックで最大化します。ペイン・タブ・パレットはウィンドウごとにあります。

「メインウィンドウに戻す」（同じキー）で、タブをメインウィンドウに戻します。文書ウィンドウを閉じても戻ります。最後のタブがなくなった文書ウィンドウは閉じます。

Web ページは、タブが別のウィンドウに移ると読み込み直し、戻る・進むの履歴は引き継ぎません。

対話ペインにも「別ウィンドウで開く」があります。「メインウィンドウに戻す」で元の位置に戻り、対話ウィンドウを閉じるとそのまま閉じます。

ウィンドウの位置と大きさは保存され、起動時に開いていたウィンドウも開き直します。メインウィンドウを閉じると Lattice は終了します。

## ライブラリを整理する

### ジャンル・タグ・難易度

記事を保存すると、AI プロバイダがジャンル・タグ（3 つまで）・難易度を付けます。ジャンルは Database・Security・Web のような大きな分類です。既存のジャンルを優先して使い、合うものがないときだけ新しいジャンルを作ります。難易度は「入門」「初級」「中級」「上級」「専門」の 5 段階で、その分野が専門ではない現役のソフトウェアエンジニアにとっての難しさです。

Reader のタイトルの下の行で変えられます。

- ジャンルと難易度はメニューから選び直せます。自分で選んだものは固定され、自動分類で変わりません。難易度を「未判定」に戻すと、もう一度推定します。
- 「+ タグ」でタグを足し、タグの × で外します。自動分類はタグを足すだけで、自分で付けたタグは消しません。
- ⋯ メニューの「自動分類」は、ジャンルと難易度の固定を外して分類し直します。

ジャンルの名前を変えるには、ナビの「ジャンル」の横の「編集」（「設定 › ジャンル」）を開きます。別のジャンルと同じ名前にすると、2 つのジャンルを統合します。記事のないジャンルは削除できます。

### 重要度

「設定 › 要約・対話」の「自分について」を書くと、新しい記事ごとに、あなたにとっての重要度を AI プロバイダが 1〜5 で判定し、理由を 1 行付けます。5 段階は「関係なし」「少し関係」「関心あり」「重要」「必読」です。

- 記事一覧では重要度 4 と 5 の記事に目印が付き、ポインタを乗せると理由が出ます。Reader ではタイトルの下に重要度と理由が出ます。
- ナビの「重要」には、下限（既定は 4）以上の記事が出ます。
- 「自分について」を書き換えると、それまでの判定には「（以前のプロフィールで判定）」と出ます。判定し直すまでは、その点数をそのまま使います。「設定 › 重要度」の「重要度を付け直す」は、未判定と以前のプロフィールの記事をすべて判定し直します。一覧の上の「重要度を付け直す」は、表示中の記事を判定し直します。

### グループ

グループは、自分で記事を集めたものです（プロジェクトや読むものリストなど）。1 つの記事を複数のグループに入れられます。

- ナビの「グループ」の「＋ 新規」で作ります。グループの ⋯ メニューで名前の変更と削除ができます。グループを削除しても記事は残ります。
- 開いている記事は、Reader の「＋ グループ」、パレットの「この記事をグループに追加…」、右クリックメニューの「グループに追加…」で入れます。
- 一覧の上の「選択」で複数の記事を選び、「グループに追加」でまとめて入れられます。
- 取り込みの画面と、グループを開いているときに保存した URL も、そのままグループに入れられます。

グループは、検索・対話・エクスポートの範囲にもなります。

### 既読とお気に入り

記事を開くと既読になります。ただし一覧か絞り込みを変えるまでは「未読」の一覧に残るので、読み進める間に一覧がずれません。`m` で既読と未読を、`s` でお気に入りの星を切り替えます。ナビの「お気に入り」に星を付けた記事が出ます。

### 一覧・絞り込み・並び順

記事一覧には、ナビで選んだ一覧を絞り込みで絞ったものが出ます。

**一覧。** 「最近追加」（7 日以内に保存）、「未読」「お気に入り」「すべての記事」「重要」、続いてグループ・ジャンル・フィードのフォルダ・フィード・「手動追加」です。ジャンルは最初に 6 つまで出し、残りはリンクから開きます。

**絞り込み。** 一覧の上のチップで「ジャンル」「タグ」「グループ」「ソース」「難易度」「重要度」「状態」を絞り込みます。「状態」は「未読」「既読」「お気に入り」「要対応」（取得か抽出に失敗した、または本文が短い）です。1 つの絞り込みの中の値は OR、別の絞り込みどうしは AND で組み合わせます。タグは「すべて含む」か「いずれか」を選べます。絞り込みの件数は、今の一覧の中での件数です。該当する記事がないときは、どの絞り込みを外すと何件になるかを一覧が示します。

`Esc` で絞り込みを解除します。パレットからも絞り込みを足せます。

**並び順。** 一覧の上の「並び順とグループ」で、「追加日・新しい順」「追加日・古い順」「公開日・新しい順」「難易度・やさしい順」「重要度・高い順」から選びます。一覧を「ソース」か「ジャンル」でまとめて表示することもできます。

**一覧の中の移動。** `j` と `k`（または `↓` と `↑`）でカーソルを動かし、`Enter` で開きます。`Shift+Enter` は Page で開きます。

### 右クリックメニュー

一覧の記事か、Reader・Page のタブを右クリックすると、その記事のメニューが開きます。キーボードではメニューキーか `Shift+F10` で開きます。

メニューには「お気に入り」「既読にする」「グループに追加…」「新しいタブで開く」「別ウィンドウで開く」「Page で開く」「URL をコピー」「Index から削除…」があります。保存していないページのタブには、そのページで使えるものだけが出ます。

### 複数の記事をまとめて操作する

一覧の上の「選択」を押し、記事をクリックして選びます。`Shift`+クリックで範囲を選べます。ボタンを押さずに `Shift`+クリックしても選択が始まります。選んだ記事を右クリックすると、全部にまとめて効く操作（お気に入り・既読と未読・「グループに追加…」）が出ます。「選択を終了」で終わります。

### Index から記事を削除する

⋯ メニューか右クリックメニューの「Index から削除…」を選び、確認します。保存した HTML・本文・ほかの記事が使っていない訳文・要約・タグ・画像・検索用のデータを削除します。元に戻せません。対話の回答の引用は残ります。フィードの記事なら、そのフィードから同じ記事を取り込み直すことはありません。

## 検索する・質問する

### 検索

`/` で保存した記事を検索します。検索は hybrid で、全文検索と意味検索を組み合わせます。日本語の検索語で英語の箇所も、その逆も見つかります。原文と訳文の両方を検索します。

- 結果は記事ごとにまとめた箇所の一覧です。`j` と `k` で移動し、`Enter` でその箇所を Reader で、`Shift+Enter` で Page で開きます。`Esc` で一覧に戻ります。
- 範囲のメニューで「最近追加」「未読」「お気に入り」、グループ、ジャンル、フィードに絞れます。絞り込みのチップでさらに絞れます。
- 「検索方式」で、一致の種類ごとに結果を絞ります: 「Hybrid」「全文」「意味」「全文 + 意味」。検索そのものは常に両方の方式で行います。
- 検索中は、ナビに最近の検索が出ます。

意味検索は multilingual-e5-small モデル（約 470 MB）を手元の PC で動かします。モデルは最初の検索のときにダウンロードします。準備ができるまでは全文検索の結果だけを出し、その理由を結果に表示します。

### コマンドパレット

`Ctrl+K` か、タイトルバーの箱のクリックでパレットを開きます。入力すると、記事のタイトル・タグ・ソース・ジャンル・コマンドをまとめて探します。

| 先頭の文字 | 探すもの |
|---|---|
| `#` | タグ |
| `@` | ソース（フィードとフォルダ） |
| `g:` | ジャンル |
| `>` | コマンドだけ |
| `?` | 保存した記事の検索 |

- `Enter` で選んでいる項目を実行します。`Ctrl`+クリックで記事を新しいタブに開きます。
- `Tab` で、選んでいるタグ・ソース・ジャンルを絞り込みに足し、パレットは開いたままにします。いくつも重ねられます。
- `Ctrl+Enter` で入力した語を検索します。
- URL を貼ると、「Page で開く」「Index に追加（取り込み）」「フィードを検出して登録」が出ます。
- コマンドには、一覧の切り替え、「表示言語: 混在」（`70` のように数を付けると割合も決まります）、「この記事を翻訳（job を積む）」「今日の復習を開く」「単語帳を開く」「処理状況を開く」「失敗したジョブをすべて再実行」「対話を開く」「フィードを管理」「一括インポート」「Markdown を取り込む」「PDF（論文）を取り込む」「設定を開く」などがあります。

### 保存した記事に質問する

ナビの「対話」で対話ペインを開きます。質問すると、保存した記事だけをもとに回答します。回答の中の番号は引用で、押すと根拠の箇所が開きます。範囲の記事に関係する箇所がなければ、推測せずにそう答えます。

「範囲」で、回答のもとにする記事を選びます。

- 「この記事」は、フォーカスのあるタブの記事です。
- 「開いている記事すべて（3 件）」は、すべてのウィンドウのタブで開いている保存済みの記事です。「開いている記事」の下に 1 件ずつも選べます。
- 「全記事」、今の一覧、グループ、ジャンル、フィード、フォルダ、タグ。

範囲の本文が収まれば全文を送ります。収まらなければ、検索で関係が深い箇所を 1 記事 4 箇所まで選び、多くの記事から集めて送ります。回答にはどちらの方法で答えたかが出ます。1 回の質問で送る量は、「設定 › 要約・対話」の「対話で使う範囲」で決めます。

- `Ctrl+Enter` で送信します。
- 続けて質問すると、直前の 3 往復も踏まえて答えます。
- 会話は保存されます。会話の題名のメニューから、保存した会話・「新しい会話」・「この会話を削除」を選べます。
- Reader の「質問」で、その記事について対話を始めます。
- 対話ペインの「別ウィンドウで開く」で、対話を別のウィンドウに移せます。[タブを別ウィンドウで開く](#タブを別ウィンドウで開く)を参照してください。
- Vim のキーで入力するには、「質問の入力欄で Vim キーバインドを使う」をオンにします。

## 読んだ内容を身につける

### 理解度チェック

Reader か Page のツールバーの「理解度チェック」で、記事の横にパネルが開きます。「クイズを作成」で、記事の要点を確かめる問題を 3〜8 問作ります（記述式と 4 択）。

1. 4 択なら選択肢を選びます。記述式なら答えを思い浮かべ（「自分の答え」に書くこともできます。保存はされません）、「答えを見る」を押します。
2. 答え・解説・出典を読みます。出典を押すと本文のその箇所に移ります。
3. 「もう一度」「難しい」「正解」「簡単」で自己評価します。`1`〜`4` のキーでも選べます。4 択では答えに合わせた評価が選ばれていて、変えることもできます。

最後に「復習に追加」すると、問題が[今日の復習](#今日の復習)に入ります。答えた結果は 1 回目の復習として記録します。「もう一度解く」で最初からやり直せます。本文か「自分について」が変わったら、「作り直す」で新しい問題を作れます。

パネルの状態は、別の画面やタブに移って戻っても残ります。Lattice を再起動すると消えます。

### 単語を登録する

知らない英単語や熟語があったら、Reader で選択して「単語を登録」を押すか、`w` を押します。Page 表示では、文字を選択するとページの上に同じボタンが出ます。単語は、出てきた文と記事と一緒に保存されます。

その後、AI プロバイダが見出し語・品詞・英語の定義・例文・発音（IPA）・日本語の意味を付けます。同じ語の別の形はまとまります。run を登録した後に ran を登録すると、run の項目に文が増えます。

登録した語は記事の中で下線付きで表示され、ポインタを乗せると意味が出ます。

選択できるのは、英字を含み、改行をまたがない 64 文字までの語です。

### 単語帳

「ツール」の「単語帳」に登録した語の一覧があります。

- 「単語・意味で検索」で絞り込み、「追加が新しい順」か「復習の期限が近い順」で並べます。
- 語ごとの ⋯ メニューに「意味を編集」「意味と例文を再生成」「復習を停止」（または「復習を再開」）「削除」があります。意味の取得に失敗した語には「意味をもう一度取得」が出ます。
- 「記事中の登録語に下線を引く」で、記事の中の下線をオン・オフします。
- 「CSV に書き出す」で、Anki に読み込める CSV（表・裏・タグ）を `exports` フォルダに書き出します。

### 今日の復習

ナビの「今日の復習」に、期限が来たカードの枚数が出ます。理解度チェックの問題と単語のカードを 1 枚ずつ出題し、Anki と同じ SM-2 方式で間隔を空けます。

- 単語のカードは、表に見出し語・IPA・品詞が出て、見出し語を読み上げます。裏には英語の意味・例文・日本語の意味・登録した文・「出典へ」があります。「発音を聞く」「例文を聞く」か `r` で、もう一度聞けます。
- 評価のボタンには、次に出題される時期が出ます。ボタンか `1`〜`4` で評価します。
- カードの ⋯ メニューで、そのカードかその記事全体を復習から外せます。単語なら「この単語の復習を停止（単語帳で再開）」で止められます。
- 終わると、復習した枚数と次のカードの時期が出ます。復習中の記事の一覧から、記事ごとに外すこともできます。

正解するたびに間隔が伸びます（1 日、6 日、その後は約 2.5 倍ずつ）。「もう一度」で最短間隔に戻ります。1 日の上限と間隔は「設定 › 復習」で変えられます。日付は PC の時刻の 0 時で変わります。

読み上げには Windows の英語の音声を使い、オフラインで動きます。英語の音声がない PC では、スピーカーのボタンは出ません。

## バックグラウンドの処理

取得・描画・翻訳など時間のかかる処理は、ジョブとしてバックグラウンドで動きます。「ツール」の「処理状況」で確認できます。失敗したジョブがあると、ナビに赤い件数が出ます。

| ジョブ | 内容 |
|---|---|
| 「取得」 | URL のページを取得して本文を取り出し、記事として保存します。 |
| 「描画」 | 取得しただけでは本文が取れないページを裏のブラウザで描画し、保存し直します。 |
| 「画像」 | 記事の画像をダウンロードして保存します。 |
| 「サイトアイコン」 | フィードや記事の横に出すサイトのアイコンを取得します。 |
| 「検索 index」 | 検索のために記事の段落をベクトルにします。手元の PC で動きます。 |
| 「翻訳」 | 記事の段落を AI プロバイダで翻訳します。 |
| 「要約」 | 記事の要約を作ります。 |
| 「クイズ」 | 理解度チェックの問題を作ります。 |
| 「単語の意味」 | 登録した単語に意味・定義・発音・例文を付けます。 |
| 「分類」 | 記事にジャンル・タグ・難易度を付けます（1 回の呼び出しで最大 20 件）。 |
| 「重要度」 | 「自分について」を基準に記事の重要度を付けます（1 回の呼び出しで最大 20 件）。 |
| 「取り込みフィルタ」 | フィードの新着を取り込むかを LLM で判定します（1 回の呼び出しで最大 20 件）。 |

アプリでも、種類ごとの ⓘ で説明を見られます。

ジョブの状態は「待機」「実行中」「再試行待ち」「失敗」です。失敗したジョブは 2・4・8・16 分の間隔を空けて自動で再試行し、5 回で止まります。「今すぐ再実行」で待っているジョブをすぐ実行し、「再実行」で失敗したジョブをもう一度実行します。「失敗を再実行」と「失敗をすべて再実行」は、種類ごと・全体でまとめて実行します。「取り消し」は待機中か失敗したジョブを消します。実行中のジョブは取り消せません。

同じサイトへの取得は 1 本ずつ行うので、一括インポートでサイトに負荷が集中しません。

## 設定

ナビのいちばん下の「設定」で開きます。セクションは「AI」「ライブラリ」「操作」「データ」「アプリ」に分かれています。「ライブラリ」の「フィード →」は「フィードを管理」を開きます。

### AI プロバイダ

翻訳・要約・分類・重要度・理解度チェック・単語の意味・LLM の取り込みフィルタ・対話には AI プロバイダが必要です。使えるのは次のプロバイダです。

| プロバイダ | 必要なもの |
|---|---|
| Claude CLI | `claude` コマンド（インストールしてログイン済み） |
| Codex CLI | `codex` コマンド（インストールしてログイン済み） |
| OpenAI API | API キー |
| Gemini API | API キー |
| Anthropic API | API キー |

最大 3 段まで並べられます。1 段目から使い、呼び出しが失敗したら（usage limit など）次の段に切り替えます。失敗した段は 5 分間後回しにします。段はドラッグで並べ替えます。キーボードでは `Space` で持ち上げ、矢印キーで動かし、もう一度 `Space` で置きます。

段ごとに、プロバイダ・モデル・effort（どれだけ深く考えるか）を選びます。「その他（モデル ID を入力）」で任意のモデル ID を使えます。effort を上げると品質が上がることがある代わりに、遅く高くなります。大量に翻訳するなら、速いモデルと低い effort がおすすめです。モデルが対応しない effort を選ぶと、その段は失敗して次の段に進みます。

「API キー」で API のプロバイダのキーを入力します。キーは Lattice の DB に保存し、二度と表示せず、バックアップとエクスポートには含めません。キーを保存していなければ、環境変数 `OPENAI_API_KEY`・`GEMINI_API_KEY`・`ANTHROPIC_API_KEY` を読みます。

### 翻訳

| 設定 | 内容 |
|---|---|
| 「表示を切り替えたら自動で翻訳」 | Reader で「混在」か「訳文」に切り替えたら翻訳を始めます。既定はオン。この PC だけの設定です。 |
| 「保存した記事を自動で翻訳」 | 記事を保存したらすぐに翻訳します。記事ごとにプロバイダを使うので、既定はオフです。日本語の記事は訳しません。 |
| 「専門用語を英語のまま残す」 | 日本語に訳すとき、MVCC や write skew のような用語を英語のまま残します。英語に訳すときは、定着した英語の用語を使います。既定はオン。 |
| 「追加の指示」 | 翻訳の prompt の末尾に付け加える指示です（文体や訳語の指定など）。2,000 文字まで。「組み込みの prompt（英語→日本語）を見る」で、付け加える先の prompt を確認できます。 |

どちらの設定も、Reader とページ表示の翻訳の両方に効きます。訳文は設定ごとに別に保存するので、変えた後は記事を訳し直す必要があります。元の設定に戻せば以前の訳文が出ます。

### 要約・対話

| 設定 | 内容 |
|---|---|
| 「自分について」 | 仕事・関心・前提にしてよい知識などです。要約・対話の回答・理解度チェック・重要度・LLM の取り込みフィルタに反映します。2,000 文字まで。 |
| 「要約の追加の指示」 | 要約だけに付け加える指示です。変えると、作成済みの要約に、作り直せば反映される旨が出ます。 |
| 「対話の追加の指示」 | 対話の回答だけに付け加える指示です。次の質問から効きます。 |
| 「対話で使う範囲」 | 1 回の質問で送る記事の量です: 「少なめ（約 4 万字）」「標準（約 8 万字）」「多め（約 15 万字）」。多いほど網羅的に答えますが、1 回のコストと待ち時間が増えます。 |
| 「質問の入力欄で Vim キーバインドを使う」 | 対話の入力欄で Vim のキーを使います。挿入モードで始まり、`Esc` でノーマルモードになります。送信はどちらのモードでも `Ctrl+Enter` です。この PC だけの設定です。 |

### 自動分類

「保存した記事を LLM でジャンル分けし、タグを付ける」は既定でオンです。「未分類をすべて分類」で、ジャンルか難易度のない記事をすべて分類の待ち行列に入れます。

### 重要度

「新しく保存した記事の重要度を判定する」は、「自分について」があるときだけ新しい記事を判定します。「「重要」に入れる重要度」で、ナビの「重要」に出す下限を決めます。「重要度を付け直す」で、未判定と以前のプロフィールで判定した記事を判定し直します。

### ジャンル

すべてのジャンルと記事数の一覧です。名前の変更・統合・削除ができます。[ジャンル・タグ・難易度](#ジャンルタグ難易度)を参照してください。

### 取り込み・JS 描画

「JS ページを自動で描画」で、本文がほとんど取れなかった記事を描画し直します。[JavaScript で描画するページ](#javascript-で描画するページ)を参照してください。

### 取り込みフィルタ

すべてのフィードに効く全体のフィルタです。[フィードを登録する](#フィードを登録する)を参照してください。

### 画像

「画像を保存する」で、記事の画像（PNG・JPEG・GIF・WebP・AVIF）をダウンロードして DB に保存します。SVG はリンクのままにします。「1 枚あたりの上限」は既定 5 MB で、1〜20 MB にできます。記事 1 件あたりは 30 MB までです。オフにしても保存済みの画像は消えません。

### 復習

| 設定 | 既定 |
|---|---|
| 「1 日の新規カード」 | 20 枚 |
| 「1 日の復習」 | 200 枚 |
| 「最短間隔」 | 1 日。1 日より短くすると、その日のうちにもう一度出題します（Anki の学習ステップと同じ）。 |
| 「最長間隔」 | 365 日 |
| 「単語カードの発音を自動で再生」 | オン。この PC だけの設定です。 |

上限は、理解度チェックのカードと単語のカードの合計です。

### 表示言語

アプリの言語を日本語か英語から選びます。最初はシステムの言語で起動し、選ぶとすぐ、再起動なしに切り替わります。記事を訳す向きは変わりません。

### ショートカット

すべてのショートカットの一覧です。「+ キーを追加」を押すと、次に押したキーを記録します（修飾キーとの組み合わせも可）。1 つの操作に複数のキーを割り当てられます。同じキーが 2 つの操作にあるときは一覧の上の操作が優先され、警告が出ます。「既定に戻す」で 1 つの操作を、「すべて既定に戻す」で全部を既定に戻します。ショートカットはこの PC だけの設定です。

### ブラウザ

「検索エンジン」は、URL バーに入力した語の検索とホームボタンに使います。DuckDuckGo（既定）・Google・Bing・Brave Search・Kagi・「カスタム」から選びます。カスタムでは、検索語の位置に `%s` を書いた「検索 URL」を入力します。

### タスクバー

「未読数をタスクバーに表示」で、未読の記事数をタスクバーのボタンに重ねて表示します。100 件以上は 99+ で、0 件のときは表示しません。

### バックアップ

「今すぐバックアップ」で、DB のコピーを `backups` フォルダに書き出します。「残す世代数」（既定 30）を超えた古いコピーは削除します。日数では消しません。

### クラウドバックアップ（R2）

DB のコピーを gzip で圧縮し（API キーは除きます）、Cloudflare R2 の bucket に定期的にアップロードします。Account ID・bucket・Access Key ID・Secret Access Key を入れて「自動バックアップ」をオンにし、「間隔（時間）」（既定 24）と「残す世代数」（既定 30）を決めます。「今すぐ R2 にバックアップ」ですぐに 1 回実行します。複数の PC から同じ bucket にバックアップできます。

bucket を作る Terraform と、アクセスキーの作り方・復元の手順は [`infra/r2`](../infra/r2/README.md) にあります。復元は手動です。

### エクスポート

「エクスポートする範囲」で、ライブラリ全体か 1 つのグループを選びます。「エクスポート」で、gzip した JSON Lines を `exports` フォルダに書き出します。記事・ブロック・訳文・要約・タグ・ジャンル・フィードとフォルダ・グループ・クイズ・対話が入ります。1 つのグループのエクスポートには対話は入りません。API キーなどの設定・取得した HTML・画像・検索用のベクトルは含みません。それらも残すにはバックアップを使ってください。

### ログ・保存場所

DB・バックアップ・エクスポート・検索モデル・ログの場所を表示します。「変更…」でデータを別のフォルダに移せます。[データの保存場所](#データの保存場所)を参照してください。

### アップデート

「更新を確認」で、GitHub の Releases に新しいバージョンがあるか確認します。起動時にも確認し、新しいバージョンがあればタイトルバーの下にバーを出します。バーには「リリースノート」「更新して再起動」「後で」があります。更新は署名を確かめてからインストールし、データはそのまま残ります。ポータブル版は、新しい zip の `Lattice.exe` で置き換えて更新します。

Web ページをクリックすると、キーボードの入力はページに行きます。それでも Lattice は自分のショートカットを拾います。

- `Alt+←`・`Alt+→`・マウスのボタンはページの履歴を移動します。`w` と `r` はページでは効きません。単語はページの上のボタンで登録します。

## CLI と MCP

`lattice-cli` は、ライブラリをターミナルから読み書きし、Claude Code などの AI エージェントに MCP で提供します。ポータブル版の zip の `Lattice.exe` の隣にあります。アプリと同じデータ（ポータブル版の `data` フォルダや、「設定 › ログ・保存場所」で選んだフォルダも含む）を使い、アプリの起動中も使えます。

### コマンド

```bash
lattice-cli search "MVCC write skew" --limit 5
```

```bash
lattice-cli --format text get 42
```

| コマンド | 内容 |
|---|---|
| `search 検索語` | 保存した本文を hybrid で検索します。`--scope`、`--limit`（既定 20）。 |
| `get ID` | 1 つの記事のメタデータ・要約・本文です。`--blocks` で block を ID 付きで、`--translation` で保存済みの訳文も出します。 |
| `list` | 保存した記事を新しい順に出します。`--scope`、`--limit`（既定 50）。 |
| `summary ID` | 記事の保存済みの要約です。 |
| `tags` | タグと記事数です。 |
| `genres` | ジャンルと記事数です。 |
| `feeds` | 登録したフィードとそのフォルダです。 |
| `jobs` | 待機中・実行中・失敗したジョブです。 |
| `ask 質問` | 保存した記事をもとに、引用付きで回答します。アプリで設定した AI プロバイダを使います。`--scope`。 |
| `save URL` | URL を保存します。書き込みの許可が必要です。`--run` を付けると、アプリに任せずにその場で取得します。 |
| `tag ID 名前` | タグを付けます。書き込みの許可が必要です。 |
| `read ID` | 既読にします。書き込みの許可が必要です。 |
| `favorite ID` | お気に入りにします。書き込みの許可が必要です。 |
| `mcp` | これらのコマンドを、stdio の MCP サーバーとしてエージェントに提供します。 |

どのコマンドにも使えるオプション:

- `--format json`（既定）か `--format text`（人が読みやすい形）。
- `--data-dir パス` で別のデータフォルダを使います。
- `--allow-write` で `save`・`tag`・`read`・`favorite` を許可します。環境変数 `LATTICE_ALLOW_WRITE=1` でも同じです。

一覧は `lattice-cli --help` で見られます。

### 範囲の指定

`--scope` には次のどれかを指定します。

| 範囲 | 対象の記事 |
|---|---|
| `all` | すべての記事（既定） |
| `unread` | 未読の記事 |
| `favorites` | お気に入りの記事 |
| `tag:名前` | そのタグの記事 |
| `genre:名前` | そのジャンルの記事 |
| `feed:ID` | そのフィードの記事 |
| `folder:ID` | そのフォルダのフィードの記事 |
| `group:ID` | そのグループの記事 |
| `important` か `important:下限` | 重要度が下限（既定 4）以上の記事 |
| `article:ID` か `article:3,7` | 指定した記事 |

フィードとフォルダの ID は `feeds` で分かります。

### CLI でできること・できないこと

- 検索はアプリと同じです。アプリがまだ意味検索のモデルをダウンロードしていなければ、CLI はダウンロードせず全文検索だけで答え、JSON にそう書きます。
- `ask` の質問は、アプリの対話の履歴にも残ります。
- `save` は取得を待ち行列に入れ、起動中のアプリが 30 秒以内に処理します。`--run` を付けると、CLI がページ・画像・（モデルがあれば）検索用のベクトルを自分で取得します。分類と描画はアプリに残ります。
- `tag`・`read`・`favorite` の変更は、アプリが次に一覧を読み直したときに反映されます。
- お気に入りや既読の解除、タグの削除、記事の削除はできません。エージェントに渡すのは、取り消しやすい操作だけにしています。

### Claude Code から使う

```bash
claude mcp add lattice -- lattice-cli mcp
```

エージェントは `search`・`get`・`list`・`summary`・`tags`・`genres`・`feeds`・`jobs`・`ask` を tool として使えます。`save`・`tag`・`read`・`favorite` も渡すには、`mcp` の後に `--allow-write` を付けます。

### prompt injection に注意する

保存した記事は、他人が書いた Web ページです。それを読むエージェントは、本文に隠れた指示に誘導されることがあります。tool の結果の先頭には、内容が信頼できない外部の文章で、その指示に従ってはならないという注意を付けています。結果は 25,000 文字で切ります。それでも危険はなくなりません。

- 必要なとき以外は、書き込みを許可しないでください。
- 記事を読ませるエージェントのセッションに、シェル・ファイルの書き込み・メールのような危険な tool を同時に渡さないでください。

## データ・プライバシー・安全

### データの保存場所

データはすべて 1 つの SQLite ファイルにあります。記事・取得した HTML・訳文・要約・画像・検索用のデータ・対話・クイズ・単語・設定です。

| もの | 場所（インストール版） |
|---|---|
| DB | `%APPDATA%\dev.lattice.app\lattice.db` |
| バックアップ | `%APPDATA%\dev.lattice.app\backups\` |
| エクスポート（JSON・CSV・OPML） | `%APPDATA%\dev.lattice.app\exports\` |
| 意味検索のモデル | `%APPDATA%\dev.lattice.app\models\` |
| ログ | `%LOCALAPPDATA%\dev.lattice.app\logs\` |

正確なパスは「設定 › ログ・保存場所」に出ます。

**ポータブル版。** すべて（ログとアプリ内ブラウザの Cookie・キャッシュも）を `Lattice.exe` の隣の `data` フォルダに置きます。

**データを移す。** 「設定 › ログ・保存場所」の「変更…」でフォルダを選びます。DB・バックアップ・エクスポート・検索モデルをそこへコピーし、再起動後から新しいフォルダを使います。コピーの後に変えたものは新しい場所に入らないので、すぐに再起動してください。元のデータは消さないので、不要になったら自分で削除してください。選んだフォルダにすでに Lattice のデータがあれば、コピーせずにそのデータに切り替えます。起動時にそのフォルダを使えないときは既定の場所で起動し、設定画面に理由を出します。

いくつかの好みは、DB ではなくこの PC に保存します。ショートカット、検索エンジン、「表示を切り替えたら自動で翻訳」、Vim の設定、読み上げ、下線、フォルダの開閉、ウィンドウのレイアウトです。これらはバックアップに入りません。

### AI プロバイダに送るもの

設定した AI プロバイダに文章を送るのは、次の機能を使うときだけです。

| 機能 | 送るもの |
|---|---|
| 翻訳 | 訳す段落と、翻訳の追加の指示 |
| ページ表示の翻訳 | 表示中のページの段落（「混在」か「訳文」のときだけ） |
| 要約 | 記事の本文、「自分について」、要約の追加の指示 |
| 分類 | タイトル、ドメイン、要約か本文の冒頭 |
| 重要度 | タイトル、ドメイン、要約か本文の冒頭、「自分について」 |
| 理解度チェック | 記事の本文、「自分について」 |
| 単語の意味 | 単語と、登録したときの文 |
| LLM の取り込みフィルタ | 新着のタイトルと抜粋、「自分について」、指示 |
| 対話 | 質問、範囲の記事の本文、直前の 3 往復、「自分について」、対話の追加の指示 |

意味検索・読み上げ・本文の抽出は手元の PC で動きます。CLI のプロバイダは、その CLI にあなたがしたログインを使います。

### API キー

API キーと R2 の Secret はローカルの DB に保存します。二度と表示せず、バックアップ・R2 へのアップロード・エクスポートには含めません。「設定 › ログ・保存場所」の「変更…」でデータを移すときは、DB と一緒に新しいフォルダへコピーします。

### 記事の内容は信頼しない

保存したページは他人が書いたものなので、Lattice はその内容を指示ではなくデータとして扱います。

- 記事の本文はプレーンテキストとして表示します。記事の HTML が Lattice のウィンドウの中で動くことはありません。
- Web ページは別のブラウザで動きます。そのブラウザは http と https のアドレスしか開けず、Lattice の機能はごく一部しか呼べません。
- AI プロバイダに tool は渡しません。CLI のプロバイダは、tool・MCP サーバー・ユーザー設定を無効にし、空の一時フォルダで実行します。どの prompt でも、記事の中の指示に従わないよう指示しています。
- ページに戻す訳文は、スクリプトや危険なリンクを取り除いてから差し込みます。
- 画像やサイトのアイコンのダウンロードと、フィードの検出では、プライベートネットワークのアドレスにはアクセスしません。

## 困ったときは

### 翻訳が止まって見える

- 「処理状況」を開きます。翻訳のジョブが「実行中」なら、まだ処理しています。CLI のプロバイダでは、長い記事の 1 回の呼び出しに数分かかることがあります。各 AI ジョブにかかった時間はログに残ります。
- 「再試行待ち」のジョブは失敗していて、usage limit の後などにもう一度試します。「今すぐ再実行」ですぐに実行できます。
- ツールバーに「残りを翻訳」が出ていれば、まだ訳していない部分があります。押してください。
- 日本語の記事は英語に訳します。言語の判定の誤りではありません。
- 何も起きないときは、「設定 › AI プロバイダ」を確認してください。AI プロバイダを使う機能には、動く段が 1 つ以上必要です。

### 検索で全文検索の結果しか出ない

検索結果に、全文検索のみで表示している理由が出ます。多くは、意味検索のモデルがまだダウンロード中か、試したときにオフラインだったためです。「再試行」でもう一度試します。新しい記事は、「検索 index」のジョブが終わると意味検索の対象になります。

### ページを保存できない・本文が短い

- 「取得失敗」の記事は、ダウンロードできなかったものです。ブラウザ以外を断るサイトもあります。Page で開いて「Index に追加」を押すか、保存済みなら「表示中のページで取り込み直す」を選びます。
- 「本文が短い」の記事は、JavaScript で描くページかもしれません。⋯ メニューの「描画して取り込み直す」か、上の Page 表示の方法を使います。
- ログインが必要なサイトは、先に Page 表示でログインしてください。ページを描画する裏のブラウザも、そのログインを使います。
- スキャンした画像だけの PDF には、取り込める本文がありません。

### フィードから思ったように取り込まれない

- 「フィードを管理」で、フィードごとのエラーを確認できます。「すべて更新」で全フィードを今すぐ確認します。
- 「編集」の中の「除外された記事」に、フィルタで除いた記事が理由と一緒に残っていないか確認します。
- 新しく登録したフィードは、最新の 20 件だけを取り込みます。

### Web ページの上でショートカットが効かない

キーボードの入力がページに行っています。1 文字のショートカットは、ページの入力欄の外で、ページがそのキーを使っていないときだけ効きます。`Ctrl+K` はいつでも効きます。ページの外をクリックすると、キーボードが Lattice に戻ります。

### タブを移したらページを読み込み直した

タブが別のウィンドウに移ると、Web ページは読み込み直し、戻る・進むの履歴も引き継ぎません。そういう仕様です。

### Web ページの上のメニューが少し遅れて出る

Web ページに重なるメニューは、ページを静止画の後ろに隠し終えてから、一度に表示します。⋯ のボタンにポインタを乗せてから押すと速くなります。

### 空のライブラリで起動した

選んだデータフォルダが見つからないか使えないと、既定の場所で起動します。理由は「設定 › ログ・保存場所」に出ます。フォルダを直すか、「変更…」で選び直してください。

### アップデート

「設定 › アップデート」に自動更新が設定されていないと出るときは、そのビルドでは更新を確認できません。新しいバージョンは [Releases ページ](https://github.com/Maru32768/lattice/releases)から入手してください。ポータブル版は自動では更新されません。新しい zip の `Lattice.exe` で置き換えてください。

### ログの場所

`%LOCALAPPDATA%\dev.lattice.app\logs\`（ポータブル版では `data` フォルダ）にあります。失敗したジョブ・バックアップ・各 AI ジョブにかかった時間が記録されます。
