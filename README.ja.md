# Lattice

Lattice は、技術記事を集めて読み、検索するためのローカル中心のデスクトップアプリです。記事の本文は手元の PC に保存します。翻訳と要約には自分で選んだ AI プロバイダを使い、どの記事も原文と訳文を混ぜて読めます。

- **集める。** URL を保存する、アプリ内ブラウザで読んでいるページを追加する、RSS / Atom フィードを登録する（取り込むものはフィルタで絞れます）、ブックマーク・URL の一覧・Markdown・論文 PDF を取り込む、のどれでも入れられます。JavaScript で描画するページは描画してから保存します。
- **読む。** Reader は抽出した本文を表示します。原文・訳文・混在（割合を調節できる）を切り替えられ、block ごとに反転もできます。Page 表示は元のページを表示し、同じ翻訳を重ねます。文書はタブ・ペインの分割・別ウィンドウで開けます。
- **整理する。** ジャンル・タグ・難易度と、自分の関心に基づく重要度は自動で付き、手で変えられます。自分で作るグループに記事をまとめられます。一覧は scope を選び、facet を重ねて絞り込みます。
- **検索する・質問する。** 全文検索と意味検索を組み合わせた hybrid 検索なので、日本語の検索語で英語の箇所も見つかります。対話ペインは保存した記事をもとに回答し、引用から根拠の箇所に移れます。
- **身につける。** AI が作るクイズで理解度を確かめ、分からない英単語を文と一緒に登録し、どちらも間隔反復で復習できます。
- **残す。** データはすべて 1 つの SQLite ファイルにあります。ローカルバックアップ、JSON エクスポート、Cloudflare R2 への自動バックアップがあります。

## インストール

Windows 10 / 11 で動きます（WebView2 が必要です。Windows 11 には最初から入っています）。

[Releases ページ](https://github.com/Maru32768/lattice/releases)からダウンロードしてください。

- **インストーラー**（`Lattice_x.y.z_x64-setup.exe`）: インストールし、アップデートも受け取ります。
- **ポータブル版の zip**: 好きな場所に展開して `Lattice.exe` を起動します。データはすべて隣の `data` フォルダに置きます。

まだリリースが公開されていない場合は、ソースからビルドしてください: [開発者向けガイド](docs/development.md)（英語）。

## はじめ方

1. 「設定」（左下の歯車）›「AI プロバイダ」で、プロバイダを 1 つ以上設定します。翻訳・要約・分類・対話・クイズに必要です。保存・閲覧・全文検索はなしで使えます。
2. `Ctrl+K` で URL を貼り付けて開くか、ライブラリに追加します。ファイルの取り込みは「ツール」の「一括インポート」、フィードの登録は「ソース」の横の「管理」からできます。
3. 記事を開き、ツールバーで「原文」「混在」「訳文」を切り替えます。Page で元のページを開けます。

## CLI と MCP

ポータブル版の zip の `Lattice.exe` の隣にある `lattice-cli` で、ライブラリをターミナルから検索・閲覧し、Claude Code などのエージェントに MCP サーバーとして提供できます。

```bash
claude mcp add lattice -- lattice-cli mcp
```

保存した記事は他人が書いた Web ページなので、それを読むエージェントは本文に隠れた指示に誘導されることがあります。すべてのコマンドと、書き込みや危険な tool をそのエージェントから遠ざける方法は、[CLI と MCP](docs/guide.ja.md#cli-と-mcp) を読んでください。
