# Lattice

Lattice は、技術記事を集めて読み、検索するためのローカル中心のデスクトップアプリです。記事の本文は手元の PC に保存します。翻訳と要約には自分で選んだ AI プロバイダを使い、どの記事も原文と訳文を混ぜて読めます。

- **集める。** URL を保存する、アプリ内ブラウザで読んでいるページを追加する、RSS / Atom フィードを登録する（取り込むものはフィルタで絞れます）、ブックマーク・URL の一覧・Markdown・論文 PDF を取り込む、のどれでも入れられます。JavaScript で描画するページは描画してから保存します。
- **読む。** Reader は抽出した本文を表示します。原文・訳文・混在（割合を調節できる）を切り替えられ、block ごとに反転もできます。Page 表示は元のページを表示し、同じ翻訳を重ねます。文書はタブ・ペインの分割・別ウィンドウで開けます。
- **整理する。** ジャンル・タグ・難易度と、自分の関心に基づく重要度は自動で付き、手で変えられます。自分で作るグループに記事をまとめられます。一覧は scope を選び、facet を重ねて絞り込みます。
- **検索する・質問する。** 全文検索と意味検索を組み合わせた hybrid 検索なので、日本語の検索語で英語の箇所も見つかります。対話ペインは保存した記事をもとに回答し、引用から根拠の箇所に移れます。
- **身につける。** AI が作るクイズで理解度を確かめ、分からない英単語を文と一緒に登録し、どちらも間隔反復で復習できます。
- **残す。** データはすべて 1 つの SQLite ファイルにあります。ローカルバックアップ、JSON エクスポート、Cloudflare R2 への自動バックアップがあります。

## インストール

Windows 10 / 11 で動きます（WebView2 が必要です。Windows 11 には最初から入っています）。

[Releases ページ](https://github.com/Maru32768/lattice/releases)からダウンロードしてください。

- **インストーラー**（`Lattice_x.y.z_x64-setup.exe`）: インストールし、アップデートも受け取ります。
- **ポータブル版の zip**: 好きな場所に展開して `Lattice.exe` を起動します。データはすべて隣の `data` フォルダに置きます。

まだリリースが公開されていない場合は、ソースからビルドしてください: [開発者向けガイド](docs/development.md)（英語）。

## はじめ方

1. 設定（左下の歯車）› AI プロバイダ で、プロバイダを 1 つ以上設定します。翻訳・要約・分類・対話・クイズに必要です。保存・閲覧・全文検索はなしで使えます。
2. `Ctrl+K` で URL を貼り付けて開くか、ライブラリに追加します。サイドバーの ＋ から取り込みやフィードの登録もできます。
3. 記事を開き、ツールバーで 原文 / 混在 / 訳文 を切り替えます。Page で元のページを開けます。

## 設定

### 表示言語

画面は日本語か英語です。最初はシステムの言語で起動し、設定 › 表示言語 で再起動なしに切り替えられます。記事の翻訳には影響しません（日本語の記事は英語に、それ以外は日本語に訳します）。

### AI プロバイダ

設定 › AI プロバイダ で、最大 3 つのプロバイダを fallback chain として並べます。先頭から順に使い、呼び出しが失敗したら（usage limit など）次に移ります。失敗したプロバイダは 5 分間後回しにします。

| プロバイダ | 必要なもの |
|---|---|
| Claude CLI | `claude` コマンド（インストールしてログイン済み） |
| Codex CLI | `codex` コマンド（インストールしてログイン済み） |
| OpenAI API | API キー |
| Gemini API | API キー |
| Anthropic API | API キー |

API キーは 設定 › AI プロバイダ で入力します。ローカルの DB に保存し、バックアップとエクスポートには含めません。キーを保存していなければ環境変数 `OPENAI_API_KEY`・`GEMINI_API_KEY`・`ANTHROPIC_API_KEY` を読みます。

設定 › 要約・対話 で自分について（関心や前提知識）を書くと、要約・対話の回答・クイズ・重要度の判定に反映されます。

記事の本文は信頼できない入力として扱います。AI プロバイダには tool を渡しません。CLI プロバイダは tool・MCP サーバー・ユーザー設定を無効にし、空の一時ディレクトリで実行します。

### 意味検索

意味検索は multilingual-e5-small モデル（約 470 MB）をローカルで動かします。初めて使うときにダウンロードし、準備ができるまでは全文検索の結果だけを表示します。

### バックアップ

- **ローカル。** 設定 › バックアップ で DB のコピーを作り、指定した世代数だけ残します。
- **エクスポート。** 設定 › エクスポート で記事・訳文・要約・タグ・フィード・対話を gzip した JSON Lines で書き出します（全体か 1 つのグループ）。
- **Cloudflare R2。** 設定 › クラウドバックアップ（R2） で、圧縮したバックアップを定期的にアップロードします。bucket と API トークンは [`infra/r2`](infra/r2/README.md) の Terraform で作れます。

### データの保存場所

データはすべて 1 つの SQLite ファイル `%APPDATA%\dev.lattice.app\lattice.db` にあります。同じフォルダに `backups\`・`exports\`・意味検索のモデル（`models\`）があります。ログは `%LOCALAPPDATA%\dev.lattice.app\logs\` です。正確なパスは 設定 › ログ・保存場所 に表示されます。

別の場所に置くには、設定 › ログ・保存場所 の「変更…」でフォルダを選びます。DB・バックアップ・エクスポート・モデルをそこへコピーし、再起動後から新しいフォルダを使います。元のデータは残すので、不要なら自分で削除してください。

ポータブル版はすべて（ログとアプリ内ブラウザの Cookie・キャッシュも）`Lattice.exe` の隣の `data` フォルダに置きます。更新するときは、新しい zip の `Lattice.exe` で置き換えてください。

### アップデート

インストール版は起動時に Releases ページを確認し、新しい版があればその場で更新できます（設定 › アップデート）。

## キーボード

`Ctrl+K` でコマンドパレットを開きます。記事・タグ・ソース・ジャンル・グループを開く、コマンドを実行する、検索する、貼り付けた URL を開く・保存する、ができます。設定 › ショートカット にすべてのショートカットがあり、変更できます（1 つの操作に複数のキーも割り当てられます）。

## CLI と MCP

`lattice-cli` は、同じライブラリをターミナルから読み書きし、Claude Code などのエージェントに MCP サーバーとして提供します。ポータブル版の zip では `Lattice.exe` の隣に `lattice-cli.exe` があります。アプリの起動中も使えます。

```bash
lattice-cli search "MVCC write skew" --limit 5
```

```bash
lattice-cli --format text get 42
```

出力は JSON で、`--format text` で人が読む形になります。コマンドは `search`・`get`（`--blocks`・`--translation`）・`list`・`summary`・`tags`・`genres`・`feeds`・`jobs`・`ask` です。`--scope` には `unread`・`favorites`・`tag:名前`・`genre:名前`・`feed:ID`・`group:ID`・`important[:下限]`（重要度。既定 4）・`article:ID` を指定できます。一覧は `lattice-cli --help` で見られます。

- **検索** はアプリと同じ hybrid です。アプリがまだ意味検索のモデルを取得していなければ全文検索だけになり、JSON にそう書かれます。
- **質問（ask）** はアプリで設定した AI プロバイダで、保存した記事をもとに回答します。質問はアプリの対話履歴にも残ります。
- **変更**（`save`・`tag`・`read`・`favorite`）は `--allow-write` か `LATTICE_ALLOW_WRITE=1` のときだけできます。

Claude Code から使うには:

```bash
claude mcp add lattice -- lattice-cli mcp
```

search・get・list・summary・tags・genres・feeds・jobs・ask が tool として使えます。`mcp` の後に `--allow-write` を付けると save・tag・read・favorite も出します。

**prompt injection に注意してください。** 保存した記事は他人が書いた Web ページで、それを読むエージェントは本文に隠れた指示に誘導されることがあります。tool の結果にはすべて信頼できない外部の文章だと明示し、大きさに上限を設けています。それでも、必要なとき以外は書き込みを有効にせず、記事を読ませるエージェントのセッションに危険な tool（シェル・ファイルの書き込み・メールなど）を同時に渡さないでください。
